## 🎬 How to Add Your 4 Videos

Place your video files directly inside the `videos/` folder with these exact names:
- `videos/video1.mp4` &rarr; Video 1: *Our Beautiful Memories ❤️*
- `videos/video2.mp4` &rarr; Video 2: *Crazy Moments & Endless Laughter 😂*
- `videos/video3.mp4` &rarr; Video 3: *Moments I'll Always Treasure ✨*
- `videos/video4.mp4` &rarr; Video 4: *Your Special Birthday Surprise 🎂*

*(Note: The website also recognizes `video1.mp4`, etc. placed directly in the main root directory).*

---

## 🎵 How to Add Custom Background Music (Optional)

1. Put your song or instrumental in the `audio/` folder named `music.mp3`.
2. The website will automatically detect and play it! If you don't add one, the built-in gentle music box synthesizer will play automatically.

## 🚀 How to Run & Share with Tejuu

### 1. View Locally
Simply double-click `index.html` in your file explorer, or right-click and choose **Open with &rarr; Google Chrome / Edge / Safari**.

### 2. Host for Free (To send Tejuu a real link!)
You can host this website in under 1 minute for free:

#### Option A: GitHub Pages
1. Create a free repository on [GitHub](https://github.com).
2. Upload this folder's contents (`index.html`, `css/`, `js/`, `videos/`, `audio/`).
3. Go to **Settings &rarr; Pages &rarr; Branch: main &rarr; Save**.
4. GitHub gives you a live link like `https://username.github.io/repo-name` to send to Tejuu!

#### Option B: Netlify Drop (Instant Drag & Drop)
1. Visit [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire project folder into the browser window.
3. Your website is live in 10 seconds with a shareable URL!

#### Option C: Vercel
1. Install or visit [Vercel](https://vercel.com).
2. Import the folder or deploy via CLI (`npx vercel`).
