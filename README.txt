TEJUU'S BIRTHDAY SURPRISE — BACKGROUND AUDIO FOLDER (OPTIONAL)
========================================================================

The website already features an emotional, cinematic music box synthesizer
that plays an acoustic birthday lullaby out-of-the-box using the Web Audio API.

If you have a specific favorite song or instrumental MP3 you want to play instead:
  1. Place your audio file here and name it:
     music.mp3
     (or birthday.mp3)
  2. The website will automatically detect it and play your song!
